\chapter{\IfLanguageName{dutch}{Vergelijking van REST API en WebSockets}{Comparative Analysis of REST API and WebSockets}}%
\label{ch:vergelijking-van-rest-api-en-websockets}
In dit hoofdstuk worden REST API en WebSockets met elkaar vergeleken als communicatiemethoden voor het doorsturen van realtime voertuigdata naar de webapplicatie. Beide technologieën worden binnen dezelfde applicatie geïmplementeerd, zodat hun geschiktheid voor realtime voertuigmonitoring onder vergelijkbare omstandigheden kan worden onderzocht.
De vergelijking richt zich op verschillende aspecten van de communicatie, waaronder responstijd, latency, updatefrequentie, hoeveelheid dataverkeer en systeembelasting. Daarnaast wordt onderzocht hoe beide technologieën zich gedragen bij verschillende updatefrequenties. Op basis van de resultaten wordt bepaald welke communicatiemethode het meest geschikt is voor de ontwikkelde realtime monitoringapplicatie.
